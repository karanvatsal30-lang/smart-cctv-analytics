# Smart CCTV Analytics

A free hobby project for retail store CCTV analytics.

## Features

- Camera-wide people counting
- Checkout congestion monitoring
- Shelf visual-change detection
- User-defined monitoring regions
- Webcam support
- RTSP/IP camera support
- Video file upload support
- User authentication with Supabase
